# 前端体验重构

基线为 `main` 上的 `9d20846`，实施分支为 `codex/frontend-refresh`。

## 模板参考

- Minimals Starter 的 Dashboard 和 Auth Split 布局提供了侧栏分组、移动端导航抽屉和分屏表单的参考。
- Minimals 完整版的 User List、Product Skeleton 和 Course Overview 提供了筛选区、首屏骨架和指标卡的参考。
- 使用项目现有的 Vue、Element Plus 和图标实现这些模式。通过 CSS 实现入场和悬停过渡，并遵循系统的减少动态效果偏好。
